# PEPTORA — Research Peptide Labs

Sitio web oficial de PEPTORA, catálogo de péptidos de investigación (RUO).

- **Dominio:** [peptora.site](https://peptora.site)
- **Stack:** HTML, CSS y JavaScript estáticos — sin build, sin dependencias.
- **Hosting:** GitHub Pages.
- **Contacto:** WhatsApp +52 662 462 1816 · formulario en el sitio.

## Estructura
- `index.html` — todo el contenido y secciones del sitio.
- `styles.css` — sistema de diseño (tokens de color, tipografía, componentes).
- `script.js` — interacciones: navegación, catálogo de productos, formulario de contacto, animaciones de scroll.
- `assets/` — logo y recursos gráficos.
- `CNAME` — dominio personalizado para GitHub Pages.

## Desarrollo local
Al ser un sitio 100% estático, basta con abrir `index.html` en el navegador o servirlo con cualquier servidor estático:

```bash
python3 -m http.server 8000
```
